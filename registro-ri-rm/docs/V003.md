## Paso obligatorio después de subir GitHub
`Api.gs` debe agregarse también al MISMO proyecto Google Apps Script donde vive el Code.gs RI-RM.
Después:
1. Ejecutar `generarApiKeyRiRm()` una vez.
2. Volver a implementar el Web App.
3. En Cloudflare configurar:
   - `RIRM_APPS_SCRIPT_URL` = URL `/exec` del Web App RI-RM
   - `RIRM_APPS_SCRIPT_API_KEY` = clave generada.
Sin esas dos variables, la ruta mostrará que RI-RM no está configurado.
